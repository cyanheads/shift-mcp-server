# 0.1.8 — 2026-10-07

## Changed

- **Framework behavior** — Safe integer string inputs are repaired (mcp-ts-core 0.13.9), and tool errors carry request IDs (0.13.10).
- **Docker builds** cross-install production dependencies on the build platform, install OpenTelemetry at the framework's peer ranges, and remove musl-only bindings from the glibc image.
- **Packaging** excludes desktop bundles from npm and caches, logs, and development notes from MCPB; environment files and registry tokens stay out of Docker contexts.
- **Development tooling** catches definition import failures, root-level tracked secrets, and packaging drift, and validates release tag annotations before publishing.
- **CodeQL** runs one analysis per language under its matching category.
- **Documentation and metadata** refresh framework skills, recovery and telemetry guidance, environment examples, install keywords, and bundle author metadata.

## Fixed

- **MCP Registry startup** uses `npx` to invoke the package bin, removes ignored npm-script arguments, and fixes `MCP_TRANSPORT_TYPE=http` on the HTTP entry.
- **Framework antipattern checks** use portable whitespace matching.

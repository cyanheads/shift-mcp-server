# 0.1.0 — 2026-03-23

## Added

- **`shift_check_in`** — registers or updates a worker session from a gist and an optional list of declared file paths. Returns the worker ID, the coordination protocol, and the active-workers table.
- **`shift_check_out`** — ends a working session and removes it from the active worker list.
- **`shift://status`** — read-only markdown view of all active workers with their gists, files, and check-in timestamps.
- **In-memory worker session store** keyed by a 6-character uppercase alphanumeric ID, generated with collision retry.
- **Patch semantics on update** — a check-in that supplies an existing worker ID changes only the fields it provides and preserves the original `checkedInAt`.
- **Unknown-worker errors embed the active-workers table** so an agent can self-identify or start fresh.
- **`docs/tree.md`** directory structure documentation.

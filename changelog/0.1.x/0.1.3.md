# 0.1.3 — 2026-03-23

## Changed

- **`shift_check_in` and `shift_check_out` validate `workerId`** against `/^[A-Z0-9]{6}$/`, so a malformed ID is rejected before the handler runs.
- **`shift_check_out` is idempotent** — an unknown or already-checked-out ID succeeds silently instead of erroring.

## Added

- **`WORKER_ID_PATTERN`** exported from the worker store.

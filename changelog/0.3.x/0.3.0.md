# 0.3.0 — 2026-11-21

## Added

- **Declared-file overlaps.** `shift_check_in` reports normalized paths and the active peers claiming them. Use repo-relative declarations. An absolute workspace ID lets absolute paths beneath that root match their relative equivalents. ([#12](https://github.com/cyanheads/shift-mcp-server/issues/12))
- **Session liveness.** Check-in records `lastSeenAt` and adopts the calling server process. Check-in and status mark a session orphaned when the server confirms the owner exited in a shared PID namespace. ([#13](https://github.com/cyanheads/shift-mcp-server/issues/13))
- **Check-out handoffs.** Active peers can see a departing worker’s final gist, file claims, and optional summary. Visibility follows persisted join and departure order, and handoffs are pruned when their last eligible peer leaves. ([#14](https://github.com/cyanheads/shift-mcp-server/issues/14))
- Serve the workspace coordination guide at `skill://shift-guide/SKILL.md`.

## Fixed

- **Project workspace defaults.** Use the real Git root of `CLAUDE_PROJECT_DIR` or the launch directory. Outside Git, use the real directory. Clear a saved Claude Code plugin Workspace value to enable project detection. An invalid project directory gets a startup diagnostic when no explicit override is configured. ([#10](https://github.com/cyanheads/shift-mcp-server/issues/10))
- **Check-in presentation.** Flatten line breaks in the caller’s gist and file display, and distinguish a solo update from the first check-in. ([#11](https://github.com/cyanheads/shift-mcp-server/issues/11))
- **Worker ID recovery.** The unknown-worker hint directs callers to reuse their own confirmed ID or start a new session.
- **Check-out summaries.** Render multiline summaries as quoted, escaped strings in text so line breaks stay visible.

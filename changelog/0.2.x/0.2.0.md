# 0.2.0 — 2026-10-17

## Added

- Add `shift://status{?workspace}` for workspace-specific roster reads ([#6](https://github.com/cyanheads/shift-mcp-server/issues/6)).

## Changed

- **Worker rosters** persist in shared per-user SQLite across process restarts, isolated by opaque workspace identifiers. Configure `SHIFT_WORKSPACE` and `SHIFT_STATE_DIR` consistently across coordinating clients; containers require a shared writable volume ([#6](https://github.com/cyanheads/shift-mcp-server/issues/6)).
- **Worker IDs** accept six ASCII letters/digits in either case and normalize to uppercase before lookup ([#7](https://github.com/cyanheads/shift-mcp-server/issues/7)).
- **Framework guidance and packaging** align with the adopted framework; Bun package-manager and Docker images move 1.4.2 → 1.4.3.

## Fixed

- **Roster tables** escape backslashes before pipes and flatten newlines in cells, preserving raw stored and structured values ([#1](https://github.com/cyanheads/shift-mcp-server/issues/1)).
- **Status notifications** publish committed mutations from either protocol era to matching modern subscribers exactly once. Cross-process updates and the framework's legacy delivery adapter require polling ([#2](https://github.com/cyanheads/shift-mcp-server/issues/2)).
- **Check-out results** report `removed: true` only for an actual deletion; no-op results point to the workspace roster and retain optional summaries ([#3](https://github.com/cyanheads/shift-mcp-server/issues/3)).
- **Check-in guidance** reaches structured output and text once through `notice`, including the solo-worker message only when applicable ([#5](https://github.com/cyanheads/shift-mcp-server/issues/5)).
- **Concurrent startup** retries SQLite busy/locked initialization within one 3-second deadline; corrupt or unwritable storage still fails visibly.
